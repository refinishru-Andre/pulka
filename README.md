# Пулька

Веб-приложение для автоматической записи и расчёта результатов очной игры в преферанс (Питер / ленинградка с домашними конвенциями).

**Live:** https://refinishru-andre.github.io/pulka/

## Что делает

Заменяет бумажный листок пули. После каждой сдачи вводишь что произошло — приложение сразу считает пулю, гору, висты каждого игрока и показывает актуальный итог «кто кому сколько должен» в вистах.

Поддерживает:
- Игру втроём и вчетвером
- Два набора конвенций: домашние правила Андрея и турнирные ФСПР (выбираются
  перед партией и на её время не меняются)
- Обычные игры 6–10, мизер, распасы с эскалацией цены и заказа
- Полвиста, возврат виста после полвиста, вистующего сдающего
- Уход без трёх (там, где конвенции его разрешают)
- Ручную правку любой сдачи и ручную корректировку пули, горы и вистов
- Калькулятор для пулек, записанных на бумаге
- Работу без интернета: считает само устройство, облако — только копия

Разбор турнирных конвенций и расхождений между документами ФСПР — в
[QUESTIONS-FSPR.md](./QUESTIONS-FSPR.md). Правила и формулы — в [SPEC.md](./SPEC.md).

## Работа с другого компьютера

Всё, что нужно для разработки, лежит в этом репозитории — ничего не хранится
только на машине Андрея.

```bash
git clone https://github.com/refinishru-Andre/pulka.git
cd pulka
npm install        # нужен Node 18 и новее
npm run dev
```

Чтобы выкладывать (`npm run deploy`), на машине должен быть вход в GitHub с
правом записи в этот репозиторий — иначе сборка пройдёт, а публикация нет.

**Чего в репозитории нет и не должно быть:** файла `.env` с сервисным ключом
Supabase. Он нужен ТОЛЬКО скриптам `scripts/inspect-game.ts` и
`scripts/recalc-cloud.ts`, которые читают облако напрямую. Ни разработке, ни
сборке, ни выкладке он не нужен. Понадобится — ключ достаётся с сервера заново,
образец полей в `.env.example`.

**Чтобы просто играть, не нужно вообще ничего** — только ссылка на сайт.
